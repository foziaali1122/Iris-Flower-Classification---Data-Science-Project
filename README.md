# Iris-Flower-Classification-Data-Science-Project
Project Overview

This project demonstrates the classification of the famous Iris dataset using 5 Machine Learning algorithms. It covers end-to-end workflow from data exploration to model evaluation.


---

🔎 Steps Performed

1️⃣ Data Exploration & Cleaning

Loaded dataset using Pandas

Checked shape, null values, datatypes

Statistical summary with .describe()


2️⃣ Exploratory Data Analysis (EDA)

Species distribution (bar plot)

Pairplot of all features

Scatter plots (Sepal vs Petal features)

Correlation heatmap


3️⃣ Preprocessing

Label Encoding for target column Species


4️⃣ Model Training & Testing
Implemented and compared 5 models:

Logistic Regression

Decision Tree Classifier

Gaussian Naive Bayes

Support Vector Machine (SVC)

Random Forest Classifier


5️⃣ Evaluation

Accuracy Score

Confusion Matrix (Heatmap)

Classification Report (Precision, Recall, F1-score)
